# PRD-02 个性化录入(enrollment)

## 目标

支持家庭成员主动录入姓名、昵称、亲属称呼和常用求救表达(含比赛演示所选方言),生成本地识别模板,使设备能识别"呼喊指定姓名""救命""快来人"等求助表达。

## 功能需求

### 录入流程

- 入口:LCD 监测首页提供"家庭称呼与求救词录入"入口(见 PRD-04)。
- 每个姓名、称呼或方言短语采集 **3—5 次**。
- 只保存模型特征或模板 + 显示名称;不保存原始录音。
- **显示名称从预设标签选择或自动编号**(如"家庭成员 A""老伴""儿子""女儿"),板端不做自由文本输入(设备无键盘,避免隐含打字需求)。
- 录入必须由用户主动开启,界面明确告知用途;录入期间守护采集暂停并在屏幕提示(音频通路互斥,见 PRD-01)。

### 管理能力

- 已录入条目支持:查看列表、重新录入、删除,随时可用;全部操作用板载按键完成。

### 演示所需最小内容(V1 底线,不得移出)

- 至少 **2 个家庭成员声音**、**2 个姓名或亲属称呼**、**3 个求救短语**、**1 种目标方言**版本。
- 每个短语同时录制 **平静** 与 **急促** 两种表达(训练/模板与负样本用途,见 PRD-07)。

## 识别语义(与 PRD-03 联动)

- 平静、单次呼喊姓名 → 只触发本地"是否需要帮助"确认,**不远程通知**。
- 急促重复呼喊、明确求救词,或呼喊伴随呻吟等异常人声 → 升级为远程通知。
- 输出通过 `DistressObservation` 携带 `matchedPhrase`、`personLabel`、`urgency`、`repeatCount`。

## 技术方案

- 两阶段:通用人声异常检测 + 用户个性化短语/声音样本模板。
- 优先使用比环境声模型更小的独立关键词模型或 MFCC/声学嵌入模板匹配。
- 若通用关键词模型不稳定,必须保底交付本地个性化模板方案(上述最小内容)。
- 不承诺覆盖所有方言,不做完整连续语音转写。

## 验收

- 安静环境个性化求救短语召回率 ≥ 0.85。
- 覆盖不同家庭成员、近/远距离、背景电视声、普通话与方言混合条件下的召回与误报测试(见 PRD-08)。
- "听到名字就报警"不得发生:平静呼喊负样本测试通过。

## 隐私要求

- 特征/模板仅存设备本地 `/data` 分区;删除操作立即生效且不可恢复。
- 默认不保存、不上传任何完整家庭对话。
