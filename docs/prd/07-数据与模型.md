# PRD-07 数据与模型(model/)

## 目标

构建六组数据集,先在电脑端训练验证环境声景、人声异常与关键词模型,再量化部署到 Gemini-S1;全程记录数据来源与许可证。

> 数据与电脑端训练属于**模拟器线**(不依赖硬件);量化部署与性能标定属于**实机线**。

## 数据集(六组)

1. 报警声 2. 水流声 3. 破碎/撞击声 4. 呻吟/痛苦叫声 5. 姓名/求救词 6. 背景噪声与普通说话(负样本)

### 候选公开数据源(使用前逐条核对许可证并登记)

| 类别 | 候选来源 | 备注 |
|---|---|---|
| 报警声 | ESC-50(siren 等)、FSD50K(Alarm/Smoke detector/Buzzer) | 另自录真实烟感实响 |
| 水流声 | ESC-50(pouring_water/water_drops)、FSD50K(Water tap/faucet) | 自录水龙头、淋浴、漏水 |
| 破碎/撞击 | ESC-50(glass_breaking/door knock)、FSD50K(Glass/Shatter/Thump) | 自录安全替代物(摔箱、敲击) |
| 呻吟/痛苦叫声 | **公开数据稀缺,以自采/拟音为主**;VocalSound 等非语言人声集补充负样本 | 注意伦理与许可证 |
| 姓名/求救词 | 全部自录(最小集见 PRD-02) | 平静 + 急促成对录制 |
| 负样本 | ESC-50/FSD50K 背景类 + 自录电视声、交谈、做饭 | |

> 许可证注意:ESC-50、UrbanSound8K 为 CC BY-NC 系,FSD50K 逐 clip CC(含 CC0/CC-BY);比赛为非商业用途,仍需逐条登记来源、许可证与署名要求,登记表随 `model/` 提交。

### 数据要求

- **按录音来源分组切分**,同一原始录音不得同时进入训练集和测试集。
- 姓名数据必须同时包含平静呼喊负样本和急促求助正样本。
- 自采样本覆盖不同距离、音量、背景条件;原始音频只存本地/TF 卡,不进 Git,仓库只放来源说明与处理脚本。

## 训练与特征

- 统一重采样 16kHz 单声道、约 1s 窗口、50% 重叠;log-mel 或 MFCC 特征。
- 环境声音:多分类模型(int8 轻量 DS-CNN 优先,前提是仓库已有可在 Gemini-S1 编译运行的量化推理示例)。
- 人声异常:独立检测模型。
- 姓名/方言求救词:本地关键词检测或 MFCC/声学嵌入模板匹配,优先更小的独立模型。
- 电脑端先完成混淆矩阵和误报分析,再考虑板端部署。

## 电脑端验收指标

- 环境声景与人声异常模型独立测试集宏平均 F1 ≥ 0.80。
- 每个安全类别召回率 ≥ 0.80。
- 个性化求救短语安静环境召回率 ≥ 0.85。

## 模型体积与资源预算(受 16MB SPI NOR 约束)

- 环境声景 + 人声异常两个 int8 模型合计 ≤ 1MB(单个目标 ≤ 500KB)。
- 关键词模型/个性化模板 ≤ 200KB。
- 模型 + 特征代码的闪存总增量 ≤ 2MB;运行内存预算见 PRD-01。

## 板端部署与降级路线(阶段相对,不设日历日期)

| 触发条件 | 决策 |
|---|---|
| 板端量化推理示例接入 2 个工作日内未跑通 | 降级为 MFCC + 小型 MLP/线性分类器,权重导出 C 数组,不引入新推理框架 |
| 端侧识别阶段过半 CNN 仍不稳定 | 强制采用无第三方运行时的小型分类器,停止推理框架移植投入 |
| 通用关键词模型不稳定 | 保底本地个性化模板方案(2 姓名 + 3 求救短语 + 1 方言),不得移出 V1 |

V1 推理运行在 Cortex-A7,HiFi4 DSP 不作为交付前提。

## 交付物

- 数据来源/许可证登记表、重采样/切片/特征提取脚本、训练与量化导出脚本、模型指标报告与实机性能数据。
