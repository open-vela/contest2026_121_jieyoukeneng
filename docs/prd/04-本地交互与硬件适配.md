# PRD-04 本地交互与硬件适配(hardware_adapter)

## 目标

用 LCD、扬声器提示音、RGB LED 和板载按键实现本地提醒与确认闭环;端侧交互不依赖网络。

> UI 与交互逻辑属于**模拟器线**(LVGL 页面可先在模拟器开发);按键/扬声器/LED/触摸驱动属于**实机线**。

## LCD 页面(只做三个,复杂内容作页面内状态切换)

| 页面 | 内容 |
|---|---|
| 监测首页 | 在线/时间同步状态、守护状态(含"守护已暂停"提示)、最近事件摘要;"家庭称呼与求救词录入"入口(PRD-02) |
| 事件确认页 | 当前最高优先事件类型/等级/倒计时;确认操作按钮;并发事件排队提示 |
| 历史记录页 | 最近事件列表与处理状态(数据来自 PRD-05) |

## 确认操作

- 必选:**已处理**(`handled`)、**误报**(`false_alarm`)。
- 增加:**稍后提醒**(`snoozed`,语义见 PRD-03)。

## 提醒硬件方案(按原理图修正:板上无独立蜂鸣器)

| 通道 | 方案 |
|---|---|
| 声音 | 经 media 播放接口用**扬声器**播放分级提示音(提醒:短音一次;警告:间隔音 + 倒计时;紧急:急促连续音) |
| 灯光 | 板载 **WS2812 RGB LED**:守护中绿色呼吸、警告黄色闪烁、紧急红色急闪(具体 LED 以实机确认) |
| 屏幕 | LCD 页面 + 背光唤醒 |

**录放并发约束:** 提示音播放与守护采集是否支持全双工,须在实机基线第一周验证;不支持则采用时分方案——播放提示音时暂停采集,单次中断 ≤ 2 秒(见 PRD-01)。

## 输入方式

- 主输入:板载 **LRADC 按键**(原理图 SW2—SW6,约 5 键,具体键位实机确认),承担确认操作、页面切换与录入流程导航。
- 增强输入:原理图存在电容触摸(CTP,I2C);若 openvela 驱动可用则启用触摸确认,**不作为依赖项**。
- 开发/演示注入:串口命令触发五类模拟事件(与脚本注入共用入口,见 PRD-08)。

## 联网与配置

- Wi-Fi 通过 nsh(`wapi`)或预置配置文件完成配网;SSID/密码等凭证存 `/data`,不进 Git(凭证管理统一见 PRD-06)。
- 监测首页显示 Wi-Fi 与时间同步状态;联网仅供上传通道使用,不影响本地闭环。

## 板级原则

- V1 优先使用官方 Gemini-S1 板级配置(`nsh_minidisplay`),通过 defconfig 启用 LCD、音频、按键、Wi-Fi;不直接修改 `vendor/` 上游代码(见 PRD-00 仓库约定)。

## 验收

- 屏幕能显示在线状态、时间同步状态、守护状态和最近事件。
- 按键、串口或脚本可触发五类模拟事件;三种确认操作生效并正确写入事件状态。
- 三级提示音 + LED 状态色按等级正确表现;录放并发或时分方案验证通过。
- 断网状态下本地提醒、确认、日志全部可用。
