## 产品定位

- **名称:** 安聆 VelaGuard —— 无摄像头家庭异常声景 AI Agent。
- **一句话:** 面向独居长辈家庭看护,设备在本地识别异常声音和求助人声,先提醒用户,无人确认后升级为家属侧远程通知。
- **目标硬件:** 全志润芯微 Gemini-S1 R528(openvela / NuttX,`dev-ai-contest-2026` 分支)。
- **硬件 fallback:** openvela 模拟器(见下"双线并行策略")。开发板能否到手不阻塞核心交付。

## V1 功能边界(五类安全声景)

| # | 声景 | eventType | 开发顺序 |
|---|---|---|---|
| 1 | 烟雾/燃气报警蜂鸣 | `alarm_beep` | 1 |
| 2 | 呻吟/痛苦叫声/哭喊/连续呼救 | `distress_voice` | 2 |
| 3 | 持续水流/疑似漏水 | `water_flow` | 3 |
| 4 | 姓名/亲属称呼/方言求救词 | `name_call_help` | 4 |
| 5 | 玻璃破碎/重物撞击 | `impact` | 5 |

另设背景噪声与普通说话两组负样本。

**V1 不包含:** 自制 PCB、手机 App(家属侧用浏览器页面,不开发原生 App)、自建公网云服务、在线学习、HiFi4 DSP 优化、完整语音转写、全方言覆盖、多传感器融合。

> 注:Gemini-S1 板载已有 SHTC3 温湿度与 LTR-553 光感传感器(见原理图)。V1 仅允许用光感辅助夜间判定(PRD-03 可选项),不做其他传感器融合。

## 隐私红线(所有模块共同遵守)

1. 原始录音不上传、不长期保存;仅允许内存环形缓冲与开发阶段受控采样(采样数据写 TF 卡,不进主存储、不进 Git)。
2. Agent 与任何远程端只接收结构化事件摘要,不得接收原始音频或完整对话文本。
3. 个性化录入必须用户主动开启、明确告知用途,只保存声学特征/模板,支持随时查看、重录、删除。
4. Git 历史、日志、远程通知中不得出现原始家庭录音与明文密钥/凭证。

## 双线并行策略(模拟器线 + 实机线)

比赛评审接受"模拟器或硬件"运行,且开发板到手时间存在不确定性,因此全程双线并行:

- **模拟器线(不依赖硬件,立即可做):** 事件协议、风险状态机、三页面 LVGL UI、Skill 与通知控制台、模拟事件注入,全部在 openvela 模拟器 + 电脑端跑通闭环。
- **实机线(板到手后):** 音频采集、真实识别、按键/屏幕/扬声器/LED、性能标定,逐步用真实识别替换模拟事件源。
- 模拟器线的产物同时是**演示兜底**:实机识别不稳时,同一状态机用模拟事件完成完整演示。

## 系统架构

```text
板载麦克风
    ↓ 48kHz 采集 → 重采样 16kHz/单声道/1s 滑动窗口(50% 重叠)
    ├── 环境声景分类(PRD-01)
    ├── 非语言人声异常检测(PRD-01)
    └── 本地关键词/个性化模板匹配(PRD-02)
               ↓ SoundObservation / DistressObservation
事件融合与风险状态机(PRD-03) ────→ 本地事件日志(PRD-05)
    ├── LCD/扬声器提示音/RGB LED 本地提醒与确认(PRD-04)
    └── 超时未确认 → anling-home-safety Skill(PRD-06)
                        ↓ 结构化摘要 + 通知文案
              局域网演示控制台 → 家属手机浏览器实时推送
              (可选扩展:webhook 转发飞书/钉钉/ntfy 等)
```

依赖方向:**识别产生事件 → 状态机决定处置 → 硬件执行交互 → 日志保存结果 → 上传同步摘要**。端侧核心链路必须可完全离线运行;控制台/Agent/通知只消费摘要,不得反向接管端侧安全判断。

## 代码结构(遵守专属仓约定)

所有代码只放专属仓 `contest2026_121_jieyoukeneng/` 内;需要进 openvela 编译树的目录必须在 `contest2026_121_jieyoukeneng.xml` 中补 `<linkfile>` 映射:

```text
contest2026_121_jieyoukeneng/
  app/velaguard_device/        # 端侧业务应用(linkfile 映射 → packages/demos/contest2026_121_velaguard)
    audio_detector/  enrollment/  event_state_machine/
    hardware_adapter/  event_log/  uploader/
  model/                       # 数据说明、训练与量化导出脚本(不进编译树)
  prototype/console/           # 通知与演示控制台:Node.js/Express + SQLite + SSE(不进编译树)
  prototype/simulate/          # 五类模拟事件注入脚本(不进编译树)
  docs/                        # PRD、架构、演示与验收材料
  logs/                        # AI Coding 日志(按官方要求主动导出提交)
  README.md                    # 最终作品说明(提交前替换为作品 README)
```
